# AI Research Scientist

A Python and SQLite research workspace designed to organize research papers, manage evidence, track experiments, and support systematic research.

## Project Goals

- Organize and search research papers.
- Manage research questions and evidence.
- Store research notes and citations.
- Track experiments and their results.
- Maintain structured research data using SQLite.
- Generate reports and project audits.

## Technologies

- Python
- SQLite
- Jupyter Notebook / Google Colab
- Data analysis and machine learning tools

## Project Components

The project notebook contains code for research organization, evidence retrieval, paper discovery, citation management, experiment tracking, and database auditing.

## Getting Started

1. Open the Jupyter notebook in Google Colab.
2. Run the code cells in order.
3. Review the outputs and check that required files and database tables are available.

Some features may require additional setup or input data.

## Project Status

This is an educational and experimental project under development. Features should be tested before being used for research conclusions.

## Future Improvements

- Improve paper search and retrieval.
- Add stronger evidence verification.
- Expand experiment tracking and evaluation.
- Improve documentation and reproducibility.
